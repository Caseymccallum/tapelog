the shipped starter pack. Nothing below executed a tool or wrote a file.

Step 3 — from event to proposal
  Clicked "Create policy proposal ->". The workbench switched to Policy Studio
  and reported:

    From recorded call #9 · packages__lookup · recorded decision: allow
    This proposal comes from a single recorded call. One call shows what
    happened once, not what the agent intended or will do next.
    A rule matches the tool name, so it governs every future call to
    packages__lookup — not only calls that look like this one.
    Nothing here is applied. Review the rule, simulate it, and save it yourself.
    This call also has a recorded result. Adding a rule does not change or
    remove recorded evidence.
  "Which tools?" was prefilled with the exact tool name packages__lookup.
  "What should happen to these calls?" defaulted to "Require human approval"
  for an already-allowed call; no outcome was applied automatically.

Step 6 — explained built-in pack
  Selected the shell pack. Default: "Require approval". Findings: "2
  condition(s) contain a pattern that cannot match the arguments they appear to
  target. A rule with only dead conditions silently stops applying."
  Each of the two deny rules shows:
    Advanced condition: shown as source below, not simplified.
    Cannot match as written: This pattern contains % , which Cedar's like
    operator treats as a literal character rather than a wildcard, so the
    condition only matches an argument that really contains a percent sign.
    Cedar's wildcard is * .
  The raw Cedar expression is one click away under "Original Cedar condition".
  evidence: studio-shell-findings.png

Step 7 — light appearance
  Toggled Appearance. Studio, rule cards, chips and the builder render in the
  light palette with no unreadable state.
  evidence: studio-light-theme.pdf

Step 8 — saving
  "Save candidate as…" opens the browser save picker, suggests
  tapelog-candidate.yaml, and refuses a file that already contains data
  (asserted by the node test "the candidate save refuses a non-empty file").
  No server endpoint writes; the candidate is never activated.
